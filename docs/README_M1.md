# Team T10 — Checkpoint 3 — M1: Model Construction

## Purpose

M1 constructs the reference optimization model for **Storyline B — Cloud Resource Allocation, Variant 2**, using random seed `10`. The model assigns virtual machines (VMs) to physical servers while respecting server capacities, assignment requirements, and forbidden VM–server pairs.

## Model structure

The model uses assignment variables to represent whether, or to what extent in the LP relaxation, a VM is placed on a physical server. The formulation includes:

- one assignment requirement for each VM;
- CPU-capacity constraints for physical servers;
- memory-capacity constraints for physical servers;
- restrictions for forbidden VM–server assignments;
- variable bounds consistent with the reference formulation.

The LP relaxation permits fractional assignment values in the interval `[0, 1]` for eligible assignment variables. Forbidden assignment variables are fixed to zero. The complete coefficient matrices and bounds are generated by the project code.
