## Problem description

The task is to allocate 50 virtual machines to 11 physical servers. Each VM has CPU and memory requirements, and each server has finite CPU and memory capacities. Some VM–server combinations are forbidden and therefore cannot be selected.

The model represents the allocation using assignment variables. In the LP relaxation, eligible assignment variables may take fractional values between zero and one; forbidden assignments are fixed to zero.

## Constraints

The formulation enforces the following requirements:

1. **VM assignment:** every VM satisfies its assignment requirement.
2. **CPU capacity:** the total CPU demand assigned to each server does not exceed that server's CPU capacity.
3. **Memory capacity:** the total memory demand assigned to each server does not exceed that server's memory capacity.
4. **Forbidden assignments:** prohibited VM–server pairs are not allowed.
5. **Variable bounds:** assignment variables obey the bounds of the reference formulation.

The model generated for the assigned instance contains 561 variables and 116 constraint rows. It includes 51 forbidden assignment pairs.
